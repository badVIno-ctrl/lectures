Как с этим работать, чтобы запомнилось

Пять приёмов, которые проверены исследованиями памяти

  1. Сначала угадай, потом смотри. В разборах включён режим «🔮 Сначала угадай»: перед каждым ключевым числом тебя спросят ответ. Попытка вспомнить или угадать закрепляет материал сильнее, чем повторное чтение (это называют «эффектом тестирования»).
  2. Спрашивай «почему?». В каждом шаге есть блок ❓ Почему так, а часто ещё и 🔀 А если по-другому?. Понятое «почему» держится в памяти дольше, чем выученное «как».
  3. Подсказки убираются постепенно. В «Собери сам» первый шаг сделан за тебя, во втором ты считаешь сам, а в третьем ещё и сам подбираешь множитель. Так ты переходишь от готового решения к самостоятельному.
  4. Задачи вперемешку. В тренажёре типы задач идут вперемешку. Так тяжелее, но на контрольной ты сам решаешь, какой метод нужен, и этот навык как раз тренируется.
  5. Повторение с паузами. Карточки сами покажут, что пора повторить через 1, 3, 7 и 16 дней. Пять минут через день дают больше, чем час подряд накануне контрольной.

A1

Равносильные системы и три разрешённых действия

Что можно делать с уравнениями, чтобы ответ не изменился

Равносильные системы — это системы с одними и теми же решениями. Метод Гаусса — это цепочка шагов, на каждом из которых система меняется на равносильную, но более простую. В конце получается система, у которой ответ виден сразу.

⚖️ Образ: весыУравнение — это весы в равновесии. Если с обеими чашами сделать одно и то же (умножить на число, добавить равные грузы), равновесие сохранится. Если сделать что-то только с одной чашей или умножить всё на 0, весы «сломаются», и решения поменяются.

Элементарные преобразования, после которых система остаётся равносильной исходной:

  1. Умножить уравнение на число ≠ 0.
  2. Прибавить к одному уравнению другое, умноженное на число.
  3. Переставить два уравнения местами.
🧠 Запоминалка: «П-У-П»Переставь · Умножь (только не на ноль!) · Прибавь другую строку × k. Других действий в методе Гаусса нет.
❓ Почему умножать на 0 нельзя, а на любое другое число можно?
Умножение на k ≠ 0 можно отменить: поделить обратно на k. Значит, никакая информация не теряется. Умножение на 0 отменить нельзя: уравнение 2x + y = 5 превращается в 0 = 0, и его условие пропадает. Например, система {x + y = 2, x − y = 0} имеет одно решение (1; 1). Если умножить второе уравнение на 0, останется только x + y = 2, а у него решений бесконечно много. Система стала не равносильной.

По той же причине разрешено прибавление: его можно отменить вычитанием той же строки.

A2

Расширенная матрица: откуда она берётся

Убираем иксы — остаются только числа

Пока мы преобразуем систему, иксы и знаки «=» просто переписываются без изменений. Важны только коэффициенты и свободные члены (числа справа). Поэтому систему заменяют таблицей чисел — расширенной матрицей: слева коэффициенты, после вертикальной черты — правые части.

Наведи (или нажми) на член уравнения или клетку матрицы — подсветится пара.

⚠️ Три правила записи — здесь чаще всего ошибаются
  • Каждый столбец — это одна переменная. Порядок одинаковый во всех строках: x1, x2, x3…
  • Переменной нет в уравнении → пишем 0. Иначе числа «съедут» в чужой столбец.
  • x без числа — это 1, а −x — это −1.

Как читать пометки в тетради

«×(−2), ×(−4)» у строки 1 и стрелки внизСтроку 1 умножаем на −2 и прибавляем к строке, куда указывает стрелка, а потом так же на −4 и к следующей. Сама строка 1 не меняется. Здесь это записано как С₂ → С₂ − 2·С₁.
«:3» или «:(−27)» справа от строкиВся строка делится на это число. Это тоже действие «умножь на число ≠ 0» (на 1/3).
Дуга со стрелками между строкамиСтроки меняются местами: С₁ ↔ С₃.
⊖ между двумя одинаковыми строкамиВычитаем одну из другой. Получается нулевая строка, и её вычёркивают.

A3

Метод Гаусса: прямой и обратный ход

Пример 1 из лекции: решение одно

🪜 Идея одной картинкой: лестница Прямой ход — спускаемся сверху вниз и делаем нули под «ступеньками», пока матрица не станет ступенчатой (треугольной).
Обратный ход — поднимаемся снизу вверх: из последней строки находим последнюю неизвестную, подставляем её выше и так далее.

Ступенька (ведущий элемент) — первое ненулевое число строки. В ступенчатом виде каждая следующая ступенька стоит правее предыдущей, а под ступеньками только нули.

🧠 Правило множителя: «минус жертва на ступеньку»Чтобы получить 0 вместо числа a под ступенькой p, к строке с a прибавляем строку ступеньки, умноженную на k = −a / p. Проверка: a + k·p = a − a = 0.
Поэтому удобнее всего ступенька 1 или −1: тогда k — это просто число a с обратным знаком (или само a), без дробей.

Система:  

Что запомнить из примера 11) Наверх ставим строку со ступенькой ±1, чтобы не было дробей. 2) Нули в столбце делаем только строкой с его ступенькой. 3) Обратный ход идёт снизу вверх. 4) Ответ проверяем подстановкой в исходную систему.

A5

Сколько решений: теорема Кронекера–Капелли

Ответ виден по рангам ещё до обратного хода

Теорема. Система линейных уравнений совместна (имеет хотя бы одно решение) тогда и только тогда, когда ранг основной матрицы r равен рангу расширенной r. Обозначения: r — ранг матрицы коэффициентов (до черты), r — ранг с учётом столбца правых частей, n — число неизвестных.

r = r̄ = n → одно решениеСтупенька есть у каждой неизвестной.
r = r̄ < n → бесконечно многоЕсть n − r свободных переменных.
r ≠ r̄ (то есть r < r̄) → решений нетВ ступенчатом виде появилась строка 0 0 … 0 | b с b ≠ 0. Это уравнение 0 = b, а оно неверно ни при каких иксах.
❓ Откуда это, в двух фразах
После прямого хода каждая ненулевая строка — это «настоящее» уравнение, и их число равно рангу. Если какая-то строка обнулилась слева, а справа осталось число, то слева ранг на 1 меньше, чем с правой частью (r < r̄), и эта строка говорит «0 = b» → противоречие. Если противоречий нет (r = r̄), то каждая ступенька определяет свою переменную. Ступенек n → всё определено однозначно. Ступенек меньше n → лишние переменные свободны → решений бесконечно много.

И ещё: r̄ никогда не бывает меньше r. В расширенной матрице на один столбец больше, а от лишнего столбца ранг может только вырасти.
🧠 Запоминалка«Ранги равны — решения есть. Ступенек столько же, сколько неизвестных, — решение одно, меньше — бесконечно. Ноль равно пяти — решений нет».

Однородные системы: A·X = 0

Все правые части — нули

Система называется однородной, если все её свободные члены равны нулю: a11x1 + … + a1nxn = 0, …, am1x1 + … + amnxn = 0. В матричном виде: A·X = O, где A — матрица системы, X — столбец неизвестных, O — нулевой столбец.

Она всегда совместнаДописать к A нулевой столбец — ранг не изменится, значит r = r̄. Проще говоря, X = 0 (все иксы нули) подходит всегда: 0 = 0 в каждой строке. Это нулевое (тривиальное) решение.
Интересный вопрос — есть ли ненулевые?По Кронекеру–Капелли: если r = n, решение одно, и это ноль. Если r < n, решений бесконечно много, в том числе ненулевые (свободных переменных n − r).

Свойства решений (и почему они верны)

1) X — решение ⇒ α·X — тоже решение:  A(αX) = α·(AX) = α·0 = 0 2) X₁, X₂ — решения ⇒ X₁ ± X₂ — тоже:  A(X₁ ± X₂) = AX₁ ± AX₂ = 0 ± 0 = 0

Линейная комбинация решений X₁, …, Xl с любыми числами α₁, …, αl — это X = α₁X₁ + α₂X₂ + … + αlXl. Из свойств 1 и 2 следует, что линейная комбинация решений однородной системы — тоже решение.

Линейно зависимые решения: X₁, …, Xl линейно зависимы, если найдутся α₁, …, αl, не все равные нулю, такие что α₁X₁ + … + αlXl = 0. Тогда одно решение выражается через остальные: при α₁ ≠ 0 получаем X₁ = −(α₂/α₁)X₂ − … − (αl/α₁)Xl.

⚠️ Опечатка в конспектеВ тетради записано X₁ = (α₂/α₁)X₂ − …, а нужен минус и перед первым слагаемым: X₁ = −(α₂/α₁)X₂ − … − (αl/α₁)Xl. Он появляется, когда переносишь α₂X₂ + … в другую часть равенства.

B1

Ранг матрицы 4×4

Тот же прямой ход Гаусса, только без столбца правых частей

Ранг — это число «по-настоящему разных» строк: тех, которые нельзя получить из других. Элементарные преобразования ранг не меняют. Поэтому приводим матрицу к ступенчатому виду и считаем ненулевые строки.

🔍 Почему ранг именно 3, а не 4Строка 4 исходной матрицы (0 4 3 0) — это сумма строк 2 и 3: (−1 1 1 1) + (1 3 2 −1) = (0 4 3 0). Она ничего нового не добавляет, поэтому в ходе Гаусса она и обнулилась. Независимых строк 3 → rg = 3.

Множительk = −(убиваемое число) / (ступенька). Ступенька ±1 → без дробей.
Прямой ходНули под ступеньками, сверху вниз. Столбец обнуляем только строкой его ступеньки.
Обратный ходСнизу вверх: нашли последнюю неизвестную → подставили выше.
Лишние строки0 0 … 0 | 0 — вычеркнуть. Две одинаковые — вычесть и вычеркнуть.
Противоречие0 0 … 0 | b, b ≠ 0 → «0 = b» → решений нет.
Кронекер–Капеллиr ≠ r̄ → нет решений; r = r̄ = n → одно; r = r̄ < n → ∞, свободных n − r.
Свободные переменныеТе, у которых нет ступеньки. Пишем x₄ = t, x₅ = v (любые числа).
РангПривести к ступенчатому виду → число ненулевых строк. rg ≤ min(m, n).
ПараметрДелить на α только при α ≠ 0. Случай α = 0 разбирать отдельно.
Однородная A·X = 0Всегда есть X = 0. Ненулевые решения ⇔ r < n. Комбинации решений — тоже решения.
A·X = BX = A⁻¹·B (A слева → A⁻¹ слева).
X·A = BX = B·A⁻¹ (A справа → A⁻¹ справа).
A·X·B = CX = A⁻¹·C·B⁻¹. Снимаем снаружи: слева A⁻¹, справа B⁻¹.
ОбратнаяA⁻¹ = (1/|A|)·A*, где в A* дополнения Aij стоят на местах (j, i).
ПроверкаВсегда подставляй ответ в исходное уравнение. Так находятся ошибки знака.
