A1

Матричные уравнения

Неизвестное — целая матрица X

💬
Простыми словами. Делить матрицы нельзя. Вместо деления умножаем на обратную матрицу — с той же стороны, где стоит A.
A + X = B  →  X = B − A
A · X = B  →  X = A−1·B  (A слева — обратную слева)
X · A = B  →  X = B·A−1  (A справа — обратную справа)
A2

Ранг матрицы

Сколько «по-настоящему разных» строк

💬
Простыми словами. Ранг — сколько строк остаётся, когда лишние (которые получаются из других) обнулились. Приводим матрицу к «лестнице» элементарными преобразованиями (переставить строки; умножить строку на число ≠ 0; прибавить к строке другую, умноженную на число) и считаем ненулевые строки. Например, у ранг 1: вторая строка — это удвоенная первая.
A3

Системы уравнений: сколько решений и как записать

Решений бывает 0, 1 или бесконечно много — и никогда «ровно два»

💬
Простыми словами. Каждое уравнение с двумя неизвестными — прямая. Решение системы — общая точка всех прямых. Пересеклись → 1 решение; параллельны → 0; совпали → ∞. А чтобы считать, систему записывают матрицами: A·X = C (A — коэффициенты, X — неизвестные столбиком, C — правые части). Нет неизвестного в уравнении? Ставь 0 — иначе всё «съедет».
A4

Решаем систему: обратная матрица и Крамер

Два способа, когда матрица квадратная и |A| ≠ 0

💬
Простыми словами. Если |A| ≠ 0, решение ровно одно.
• Обратная матрица: X = A−1·C (C — справа).
• Крамер: xi = Δi/Δ, где Δi — это Δ, у которой i-й столбец заменён на правые части.
Если Δ = 0 — оба способа не работают. Ответ на «а что тогда?» даёт ранг.
🧭
Что выбрать? Нужна сама A−1 или много разных C → обратная матрица. «Посчитал и забыл», особенно 2×2 и 3×3 → Крамер. Главное в практике 3 — уметь находить A−1: на ней держатся оба способа, поэтому дальше её учим по-настоящему.

B1

Определитель 3×3 — правило треугольников

|A| = (3 «плюса») − (3 «минуса»)

💬
Простыми словами. Три произведения идут со знаком «+»: главная диагональ и два «треугольника» рядом с ней. Три — со знаком «−»: побочная диагональ и два её треугольника. В каждом произведении по одному числу из каждой строки и из каждого столбца. Потом: сумма плюсов минус сумма минусов.
⚠️
Ловушка №1 практики: «минус перед скобкой». −4 − (−7) это −4 + 7 = 3, а не −11. В тетради именно так и получилось 3.
B2

Алгебраические дополнения и «шахматка»

Aij = (−1)i+j · Mij

💬
Простыми словами. Берёшь клетку → вычёркиваешь её строку и столбец → считаешь определитель оставшегося 2×2 (это минор) → ставишь знак по шахматке + − + / − + − / + − +. Получилось дополнение. Девять клеток — девять дополнений.
B3

Обратная матрица 3×3 — главный пример тетради

A = (3 1 −5; 1 2 4; 3 2 −1), |A| = 3

💬
Простыми словами — 5 шагов.
1. Посчитай |A|. Ноль? Обратной нет, стоп.
2. Заполни таблицу из 9 дополнений Aij.
3. Транспонируй её (строки ↔ столбцы) — получится A*.
4. Раздели всё на |A|.
5. Проверь: A·A−1 = E (единицы по диагонали, нули вокруг).
Для 2×2 есть быстрое правило: диагональ меняем местами, у побочной — знаки, делим на |A|.

B4

При каких значениях параметра обратной нет?

A = (a² −1; 1 a) и A = (2 3x; 6 x²)

💬
Простыми словами. Обратной матрицы нет ↔ матрица вырожденная ↔ |A| = 0. Поэтому: считаем определитель (в нём будет параметр), приравниваем к нулю, решаем уравнение. Корни уравнения — это и есть «плохие» значения параметра.
⚠️
Ловушка №2: не делить на x! В тетради: 2x² − 18x = 0 → 2x(x − 9) = 0 → x = 0 и x = 9. Если поделить на x, корень x = 0 потеряется.
B5

Найти λ, чтобы B была обратной для A

A = (−3 5; −1 2), B = (2λ 5; −1 3), A·B = E

💬
Простыми словами. «A·B = E» значит «B — обратная к A». Перемножь матрицы (внутри будет λ), а потом приравняй каждую клетку к соответствующей клетке E (на диагонали 1, вне диагонали 0). Получатся уравнения на λ. Все они должны дать одно и то же λ — это и проверка.
⚠️
Ловушка №3: на диагонали E стоит 1, а не 0. В тетради: −6λ − 5 = 1 → λ = −1.
B6

Треугольная матрица и |A−1|

A = (1 2 0; 0 −1 2; 0 0 1)

💬
Простыми словами. У треугольной матрицы (под диагональю одни нули) определитель — это просто произведение чисел на диагонали: 1·(−1)·1 = −1. Обратная у неё тоже треугольная. И ещё одно золотое правило: |A−1| = 1/|A| (так что в тетради |A−1| = −1).
B7

Обратная к произведению: (AB)−1 = B−1·A−1

A = (1 0 −1; 2 3 1; 4 −1 2), B = (3 0 1; 4 1 2; 0 −1 1)

💬
Простыми словами. Носки надевают перед ботинками, а снимают — наоборот. Так и тут: (AB)−1 — это B−1 · A−1, порядок переворачивается. Проверить можно двумя путями: сначала перемножить A·B и найти обратную (как в тетради, |AB| = 21·5 = 105) — или найти B−1, A−1 и перемножить их в обратном порядке. Ответы должны совпасть.

Шпаргалка

Лекция 3 и практика 3 на одном экране

A + X = B

X = B − A. Поэлементно.

A·X = B

X = A−1·B (слева). Нужно |A| ≠ 0.

X·A = B

X = B·A−1 (справа). AB ≠ BA.

Ранг

Привести к ступенчатому виду → посчитать ненулевые строки.

A·X = C

Систему → в матрицы. Нет неизвестного → 0. X = A−1C или xi = Δi/Δ.

Определитель 3×3

(3 «плюса») − (3 «минуса»). Минус перед скобкой меняет знаки!

Дополнение

Aij = (−1)i+jMij. Шахматка: + − + / − + − / + − +.

Обратная матрица

A−1 = (1/|A|)·A*. A* = таблица Aij, транспонированная (Aij → место (j,i)).

Обратная 2×2

Диагональ — меняем местами; побочная — знаки; делим на |A|.

Проверка

A·A−1 = E. Если не E — ищи ошибку (чаще всего знак или транспонирование).

Параметр

Обратной нет ↔ |A| = 0. Решай уравнение выносом за скобку, не делением.

A·B = E

Значит B = A−1. Приравнивай клетки к E: диагональ 1, остальное 0.

Треугольная

|A| = произведение диагонали. Обратная тоже треугольная.

Свойства

|AB| = |A|·|B|. |A−1| = 1/|A|. (AB)−1 = B−1A−1.
